# Executive Presentation

`The Nuvance Portfolio — Executive Presentation` is a 20-slide click-through deck designed for sequential walkthrough. Distinct from the donor-facing pitch deck in `../deck/` — this is the executive-readout deck for the research package as a whole.

## How to view

Open `index.html` in any modern browser. Full-screen recommended (F11 / Cmd+Ctrl+F). The deck is self-contained.

## How to navigate

- **Right arrow / spacebar / click anywhere** — next slide
- **Left arrow** — previous slide
- **Home / End** — jump to first / last
- **1-9, 0** — jump directly to slide 1-9 or 10
- **Touch swipe** on mobile / tablet

## How to export to PDF for leave-behind

In any browser: **File → Print** (Cmd+P / Ctrl+P) → **Save as PDF**. The print stylesheet renders all 20 slides sequentially, one per page. Page size: Letter (8.5 × 11) recommended; orientation: landscape preserves the slide proportions best.

## Design notes

- **Typography:** Fraunces (variable serif, opsz + SOFT axes) for display; Newsreader (humanist serif) for body
- **Palette:** Cream paper, ink navy, burnt clay — same language as the bound report and the donor-pitch deck
- **Larger typographic register than the bound report** — display numerals, more whitespace, more dramatic title slides; designed for live walkthrough at typical reading distance
- **Reveal animations** — staggered rise on every slide entry; ~0.7s ease-out timing
- **Click-anywhere advance** — supports natural presentation flow without requiring keyboard reach

# Bound Report

`The Nuvance Portfolio — A Research Monograph` is a designed long-form publication of the research package, structured for sequential reading.

## How to view

Open `index.html` in any modern browser (Chrome, Safari, Firefox, Edge). The report is self-contained — typography loads from Google Fonts, the paper-grain background is inline SVG, no other dependencies.

## How to read

It reads top-to-bottom, paginated. Each "page" on screen approximates a printed page in proportion. Six parts:

1. **The strategic frame** (the merger, the case for support, methodology framing)
2. **The seven** (candidate cohort introduction)
3. **Three findings of consequence** (Bauer recalibration; Vassar Pavilion question; Dalio June 2026 integration)
4. **The gift table** (probability-weighted scenarios)
5. **A note on method** (how the research was constructed)
6. **What remains open** (questions only the recipient can answer)

## How to export to PDF

In any browser, use **File → Print** (or Cmd+P / Ctrl+P), then choose "Save as PDF" in the destination dropdown. Page size: 8.5 × 11 inches recommended. Margins: minimum / none (the report has its own margins built in).

The print stylesheet handles:
- Strips screen-only background gradients
- Each `<article class="page">` becomes a printed page (page-break-after: always)
- Grain texture lightens for print legibility

## Notes on the design

- **Typography:** Fraunces (variable serif, opsz + SOFT axes) for display; Newsreader (humanist serif) for body
- **Palette:** Cream paper, ink navy, burnt clay — the same language as the deck
- **Page architecture:** 28 designed pages with running heads, folio numerals, drop caps, marginalia, pull quotes, datum-grid statistics, candidate cards, and section openers
- **Aesthetic intent:** Editorial monograph / museum publication / fine-press book — not corporate report

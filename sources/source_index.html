Source-rigor standards applied (per user feedback at Checkpoint A)

Every research artifact in this project applies the following standards:

  1. Every factual claim has an inline source citation (URL + retrieval date, or filing identifier)
  2. Wealth, giving history, and life-event claims triangulated against ≥2 independent sources where possible
  3. Confidence labels explicit: (known), (inferred), (unknown)
  4. Negative findings reported — when expected information isn't available, that absence is documented
  5. Adversarial honesty — weaknesses, controversies, risks surfaced rather than soft-pedaled

Where Phase 0 training-data subagents could not perform live web fetches, claims are explicitly labeled as (known — training-data; needs live verification) and the orchestrator performed a verification pass (results in phase_0_verification_update.md).

## How to use this package

1. **Read the executive summary** to orient.
2. **Compare the ranked short list to your internal 250-candidate portfolio.** For each of these 7, ask: is this already in my portfolio? Is this net-new? Does my ranking differ from theirs?
3. **For candidates you plan to cultivate, read the dossier** (the deep file) and **the cheat sheet** (the meeting prep). Both are in this package.
4. **Use the warm-intro network map** to identify the right intro paths. Click any node for details. Pay attention to "avoid" edges (Joel Ehrenkranz on Low Road Foundation, etc.).
5. **For pitch-stage candidates, customize the designed deck.** See `artifacts/deck/README.md` for the workflow.
6. **Reference the playbook** for cultivation cadence and per-motivation-type pitch framing.
7. **Reference the benchmarking memo** for the pattern context — these gifts have happened at peer institutions; the playbook draws from documented patterns.

## The single most consequential recommendation

**Recalibrate the Bauer ask upward to the $50-75M+ Yale-Divinity-precedent legacy tier**, anchored on a perpetuity-endowment structure for the Jeffrey Peter Bauer NICU and Carol's chaplaincy program. The Greenwich Hospital benchmarking case study revealed that the Bauers' "Sunday-Monday connection" theological-stewardship giving philosophy supports a much higher tier than the initial Phase 3 dossier suggested — they gave $25M+ to Yale Divinity School (Carol B. Bauer Hall), Olin School for an ethics professorship, and WashU for a named medical school deanship. Applied to Norwalk Hospital, the ultimate-gift potential is $50-75M+ — materially higher than the $5-15M baseline scoping.

**The cultivation window is 12-24 months given age 95.** This is the single highest-leverage move in the entire package.

If pavilion-level naming is still institutionally available post-merger, this is the single anchor opportunity for a $100M+ ask (most directly relevant to Amy Goldman Fowler via cousin Lloyd Goldman's existing $100M+ Northwell engagement, with women's-health bridge framing).

## Realistic cumulative target

Per the Phase 0 case-for-support audit and Phase 4 benchmarking:

- **Probability-weighted expected cumulative from these 7 over 3-5 years: ~$70-110M**
